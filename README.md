# wjkoh/homebrew-tap

Created: Monday, November 23, 2026, 3:05 PM PST
License: Apache-2.0

Homebrew formulae for open-source CLI tools maintained by Woojong Koh.

## Install

Install directly without adding the tap first:

```bash
brew install wjkoh/tap/ghostbook
brew install wjkoh/tap/tgread
brew install wjkoh/tap/crashgate
```

Or add the tap once and install by name:

```bash
brew tap wjkoh/tap
brew install ghostbook tgread crashgate
```
